# my-project — agent context

Internal leave-request system. This repo root is also the ai-spector / DevKit workspace
(`docs/`, `prototype/`, `.ai-spector/`, `.docops/`).
Backend: NestJS 11 + Prisma + PostgreSQL. Frontend: React 19 + Vite + Tailwind 4.
Full setup and demo accounts: [README.md](../../README.md).

## Submodules — commit inside, then update the pointer

`backend/`, `frontend/`, `docs/`, `test/`, `e2e/` are **git submodules** on GitHub
(`https://github.com/NXT-ANH/<module>.git`, see `.gitmodules`; locally mapped to the
`github-nxtanh` SSH alias via `url.insteadOf`). SRS/design docs live in the `docs/` submodule. A change to backend code is a
commit in `backend/`, then a second commit here updating the submodule pointer.
Each submodule has its **own** `node_modules`, eslint, and prettier — run tooling from the
submodule root, never from the repo root.

## Commands

```bash
# backend/
npm run start:dev      # :3000/api/v1 · Swagger at /api/docs
npm run typecheck      # tsc --noEmit
npm run lint           # eslint {src,test,prisma}/**/*.ts
npm test               # jest — unit, no DB
npm run test:e2e       # jest --runInBand, no DB
npm run prisma:migrate # migrate dev   · prisma:deploy for CI/prod

# frontend/
npm run dev            # :5173, proxies /api → :3000 (same origin in the browser)
npm run typecheck      # tsc -b --noEmit
npm test               # vitest run
npm run e2e            # playwright, API stubbed — no stack needed
npm run e2e:live       # needs db + backend + built FE on :4173 (see README)
```

`docker compose up --build` runs the whole stack; migrations apply on backend container start.

## Gotchas

- **Commit messages must contain `[SPEC-XXX]`** — enforced by the `commit-msg` hook
  (`scripts/check_spec_id.py`, regex `\[SPEC-[A-Z0-9]+(?:-[A-Z0-9]+)*\]`). Same rule gates PR
  titles in `.github/workflows/pr-title.yml`. `Merge`/`Revert`/`fixup!`/`squash!` subjects are exempt.
  Example: `[SPEC-123] feat(backend): add create-order endpoint`
- **`pre-commit` is `fail_fast`** and runs PII scan → gitleaks → quick-lint before the commit-msg
  check. Install once: `pre-commit install --hook-type pre-commit --hook-type commit-msg`.
- **Seed from the host, not the container** — `cd backend && npm run prisma:seed`. The production
  image has no `ts-node`.
- **Error contract is uniform**: every error returns
  `{ statusCode, errorCode, message, traceId, timestamp, path }`. The frontend translates
  `errorCode`, so adding an error means adding its i18n key in `frontend/src/i18n`, not a
  hardcoded message. Never leak stacktraces in responses.
- **`x-request-id`** is generated by the frontend, logged by the backend, and echoed back as
  `traceId` — preserve it when touching the HTTP layer.
- Rate limiting is global; `/auth/login` is tightened to 5/min.

## Layout

- `backend/src/modules/` — `auth`, `users`, `leave-requests`, `health`
- `backend/src/common/` — guards, filters, decorators, dto, exceptions (cross-cutting; the error
  filter and role guards live here)
- `frontend/src/features/` — `auth`, `leave-requests`, `health` (mirrors the backend modules)
- `frontend/src/lib/` — `api-client.ts`, `format.ts` (locale-aware dates/numbers, vi vs en)
